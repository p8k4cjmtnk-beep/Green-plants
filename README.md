# By Herba — сайт-магазин

Интернет-магазин ароматических диффузоров, спреев и мыла в мочалке.
Языки: турецкий (основной), русский, английский.

## Что есть на сайте

- **Главная**: преимущества, категории, хиты продаж, «О нас», как заказать, отзывы, доставка и оплата, частые вопросы, контакты и форма обратной связи.
- **Каталог**: фильтр по категориям, поиск, сортировка по цене.
- **Страница товара**: описание, ноты аромата, объём, выбор количества, кнопка «Заказать в WhatsApp».
- **Корзина** (выезжает сбоку) с подсказкой, сколько осталось до бесплатной доставки.
- **Оформление заказа**: только оплата картой онлайн (PayTR). Перевод и оплату при получении можно включить в `data/settings.json` (`transfer`, `cash`).
- **Уведомления в Telegram** о каждом заказе, оплате и сообщении с сайта.
- Плавающие кнопки WhatsApp и Telegram, переключатель языка, адаптивная вёрстка для телефона.
- Страница с условиями продажи (KVKK, договор дистанционной продажи, возврат). Это шаблон, перед запуском его должен проверить юрист.

## Как менять содержимое (без программиста)

Всё редактируется прямо на GitHub: откройте файл → значок карандаша → внесите правки → **Commit changes**. Сайт обновится сам через 1–2 минуты.

| Что изменить | Файл |
|---|---|
| Товары, цены, наличие (общие описания категорий — в `assets/js/i18n.js`, ключи `desc.*`) | `data/products.json` |
| Телефон, WhatsApp, Telegram, Instagram, адреса, стоимость доставки, способы оплаты, IBAN, отзывы | `data/settings.json` |
| Любые надписи на сайте (на трёх языках) | `assets/js/i18n.js` |

### Товары (`data/products.json`)

```jsonc
{
  "id": "diffuser-lavender",        // уникальный код латиницей, без пробелов
  "category": "diffuser",            // diffuser | spray | soap | set
  "name": { "ru": "...", "tr": "...", "en": "..." },
  "description": { "ru": "...", "tr": "...", "en": "..." },
  "notes": { "ru": "...", "tr": "...", "en": "..." },
  "volume": "100 ml",
  "price": 450,                      // цена в лирах
  "oldPrice": 550,                   // старая цена (необязательно), покажет скидку
  "color": "#9b8ec4",                // цвет иллюстрации, пока нет фото
  "image": "",                       // путь к фото, например "assets/img/products/lavender.jpg"
  "featured": true,                  // показывать в «Хитах продаж»
  "inStock": true                    // в наличии
}
```

**Фотографии:** загрузите фото в папку `assets/img/products/` (лучше квадратные, 1000×1000, формат `.jpg` или `.webp`) и пропишите путь в поле `image`. Пока поле пустое, сайт рисует аккуратную иллюстрацию в цвете аромата.

**Логотип:** сейчас вместо логотипа стоит значок-листик и надпись. Пришлите файл логотипа, и я его вставлю.

**Отзывы:** в `data/settings.json` сейчас стоят *примеры* с пометкой «Пример отзыва». Замените их настоящими отзывами клиентов и удалите строку `"sample": true`.

## Публикация (бесплатно, Netlify)

1. Зарегистрируйтесь на [netlify.com](https://www.netlify.com) через GitHub.
2. **Add new site → Import an existing project → GitHub** → выберите этот репозиторий. Настройки сборки оставьте пустыми, всё уже задано в `netlify.toml`.
3. После публикации сайт будет доступен по адресу `*.netlify.app`. Свой домен (например, `byherba.com`, около 10–15 $ в год) подключается в **Domain management**.

### Уведомления в Telegram

1. В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен**.
2. Напишите своему боту любое сообщение (или добавьте его в группу, куда должны приходить заказы).
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}`. Это **chat id**.
4. В Netlify: **Site configuration → Environment variables** добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `TELEGRAM_CHAT_ID` — chat id
5. Нажмите **Deploys → Trigger deploy**.

Пока Telegram или PayTR не настроены, покупатель всё равно не потеряется: сайт предложит отправить заказ в WhatsApp одной кнопкой.

### Онлайн-оплата картой (PayTR)

[PayTR](https://www.paytr.com) — турецкий платёжный сервис: принимает Visa, Mastercard, Troy, оплату в рассрочку (taksit) и работает с ИП (şahıs şirketi). Для подключения нужен договор с PayTR (налоговый номер, IBAN, сайт с условиями продажи).

1. После одобрения возьмите в кабинете PayTR (**Bilgi → API Entegrasyon Bilgileri**): `Mağaza No`, `Mağaza Parola`, `Mağaza Gizli Anahtar`.
2. В Netlify добавьте переменные:
   - `PAYTR_MERCHANT_ID` — Mağaza No
   - `PAYTR_MERCHANT_KEY` — Mağaza Parola
   - `PAYTR_MERCHANT_SALT` — Mağaza Gizli Anahtar
   - `PAYTR_TEST_MODE` = `1` на время проверки (потом удалите)
3. В кабинете PayTR укажите **Bildirim URL**: `https://ВАШ-САЙТ/.netlify/functions/paytr-callback`

Когда оплата пройдёт, в Telegram придёт «✅ Заказ … оплачен».

## Запуск на своём компьютере

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Отправка заказов локально не работает, только после публикации на Netlify (или через `npx netlify dev`).
