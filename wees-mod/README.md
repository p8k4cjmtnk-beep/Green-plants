# Wees Mod — сайт-каталог детской одежды

Языки: турецкий, английский, арабский (арабский отображается справа налево).
Заказ: покупатель выбирает модель, цвет, размер и количество, собирает список
и отправляет его готовым сообщением в Instagram DM (`wees.mod`) или WhatsApp.

## Панель управления (для продавца)

Адрес: `https://ВАШ-САЙТ/admin/`. Вход по паролю.
В панели можно с телефона добавлять, менять и удалять товары, загружать фото,
менять цены, наличие и порядок товаров, номер WhatsApp и размеры.
Изменения видны на сайте сразу.

**Пароль** задаётся в Netlify: Project configuration → Environment variables →
переменная `ADMIN_PASSWORD`. После изменения переменной нажмите Deploys → Trigger deploy.

Как только продавец сохранит что-то в панели, сайт берёт товары из панели,
а не из `data/products.json`.

## Что где менять (без панели)

| Что | Файл |
|---|---|
| Модели, цвета, фото, цены | `data/products.json` |
| Instagram, WhatsApp, размеры | `data/settings.json` |
| Тексты на трёх языках | `assets/i18n.js` |
| Фото товаров | папка `img/` |

- **Цена:** `"price": null` показывает «Fiyat için yazın». Чтобы показать цену, впишите число, например `"price": 450`.
- **WhatsApp:** впишите номер в `settings.json` без `+` и пробелов, например `"whatsapp": "905321234567"`. Тогда появятся кнопки WhatsApp.
- **Размеры:** список `sizes` в `settings.json` (возраст ребёнка).
- **Фото:** сейчас вырезаны из скриншотов Instagram. Лучше заменить оригиналами (вертикальные, 3:4).

## Публикация на Netlify

Это отдельный сайт в папке `wees-mod`. В Netlify создайте новый проект из этого же
репозитория и в поле **Base directory** укажите `wees-mod`.
